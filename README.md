### 🚀 Featured Project

**Nuqta (نقطة): Cloud POS for Restaurants & Cafés**
A multi-tenant point-of-sale SaaS built with **Next.js 14** and **PostgreSQL**:

- 💳 iPad-friendly cashier screen and a live orders / kitchen board
- 📱 QR menu that customers open on their phones
- 🔔 Digital pager: customers get notified when their order is ready
- 🧾 Simplified tax invoices with QR codes
- 🔒 Data isolation between businesses using PostgreSQL **Row Level Security**
